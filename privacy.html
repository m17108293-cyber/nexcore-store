Politique de confidentialité

Dernière mise à jour : 11 mai 2026

Cette page explique de manière transparente quelles informations SecureCore collecte, comment elles sont utilisées et protégées.

En résumé : SecureCore collecte uniquement les données nécessaires au fonctionnement du bot. Aucune donnée n'est vendue, partagée ou utilisée à des fins publicitaires.

1. Informations collectées

1.1 Données fournies par Discord

Lorsque vous ajoutez SecureCore à votre serveur, le bot reçoit automatiquement les informations suivantes via l'API Discord :

  • ID du serveur et son nom (pour identifier votre serveur)
  • Liste des salons et rôles (pour appliquer la configuration)
  • Messages publics dans les salons où le bot a accès (analysés en temps réel, jamais stockés)
  • ID des membres qui interagissent avec le bot

1.2 Données du dashboard web

Lorsque vous vous connectez au dashboard via OAuth2 Discord, nous récupérons :

  • Votre identifiant Discord et nom d'utilisateur
  • La liste des serveurs où vous avez la permission "Gérer le serveur"
  • Aucun mot de passe — l'authentification est entièrement gérée par Discord

2. Utilisation des données

Les données sont utilisées uniquement pour :

  • Faire fonctionner les modules de protection (anti-raid, anti-spam, etc.)
  • Sauvegarder la configuration de votre serveur
  • Maintenir l'historique des sanctions (pour l'escalade progressive)
  • Afficher les logs et statistiques dans le dashboard

3. Stockage et sécurité

Toutes les données sont stockées sur le serveur d'hébergement de SecureCore :

  • Configuration des serveurs — fichiers JSON chiffrés au repos
  • Historique des sanctions — conservé 90 jours puis supprimé automatiquement
  • Logs — conservés 30 jours
  • Backups — conservés tant que vous ne les supprimez pas

Les messages analysés par l'IA ne sont jamais stockés. Ils sont traités en temps réel puis immédiatement oubliés.

4. Services tiers

SecureCore utilise les services tiers suivants pour la détection de menaces. Aucune donnée personnelle ne leur est transmise :

  • Hugging Face — Analyse de texte et d'images (uniquement le contenu, sans contexte)
  • VirusTotal — Vérification des URLs (uniquement les liens partagés)
  • OCR.space — Extraction de texte depuis les images

5. Vos droits (RGPD)

Conformément au RGPD, vous avez le droit de :

  • Accéder à vos données — demandez par DM au support
  • Rectifier les données incorrectes
  • Supprimer toutes vos données — retirez le bot ou contactez le support
  • Exporter vos données dans un format lisible

6. Suppression automatique

Quand vous retirez SecureCore de votre serveur :

  • La configuration est supprimée dans les 30 jours
  • L'historique des sanctions est supprimé immédiatement
  • Les backups sont conservés 30 jours puis supprimés (pour récupération accidentelle)

7. Cookies

Le site SecureCore utilise uniquement des cookies strictement nécessaires :

  • Session du dashboard (durée : la session du navigateur)
  • Aucun cookie de tracking, aucun cookie publicitaire

8. Modifications

Cette politique peut être mise à jour. Les changements importants seront annoncés sur le serveur Discord et via le bot directement.
