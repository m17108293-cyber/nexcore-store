Pourquoi nous

La fiabilité avant tout

SecureCore ne sanctionne jamais sans réfléchir. Voici comment.

🎯

Zéro faux positif

Avant chaque sanction, le bot analyse 7 critères : ancienneté du compte, ancienneté dans le serveur, rôle, historique, type de violation, position dans la hiérarchie et permissions actuelles.

if (member.age > 90j && hasRole) → ask_staff
🧠

3 couches d'IA

Patterns locaux (instantané), puis APIs gratuites (Hugging Face, VirusTotal, OCR.space), enfin analyse contextuelle (combos dangereux, attaques coordonnées). Chaque couche affine la décision.

Patterns + APIs + Contexte = Décision
⚖️

Escalade progressive

Sanctions adaptées au niveau de menace. Un compte ancien ne sera jamais banni d'un coup, même s'il agit suspectement. Le bot DM d'abord les admins supérieurs.

Warn → Mute → Kick → Ban

FAQ

Questions fréquentes

Vous trouverez peut-être votre réponse ici.

Comment ajouter SecureCore à mon serveur ?

1. Cliquez sur le bouton "Ajouter SecureCore" en haut de la page.

2. Sélectionnez votre serveur Discord et autorisez les permissions.

3. Allez dans Paramètres → Rôles et placez le rôle SecureCore tout en haut.

4. Tapez /setup wizard dans n'importe quel salon — l'assistant fait le reste.

Est-ce vraiment gratuit ? Y a-t-il un piège ?

Oui, SecureCore est 100% gratuit. Aucun module premium, aucune publicité, aucune limite cachée.

Le bot utilise des APIs gratuites (Hugging Face, VirusTotal, OCR.space) avec des quotas largement suffisants pour la majorité des serveurs.

À l'avenir, des bots et scripts optionnels seront proposés via la boutique — mais SecureCore lui-même restera gratuit.

Comment éviter les faux positifs ?

SecureCore est conçu pour minimiser les faux positifs avec son système d'analyse à 7 critères. Cependant, vous pouvez ajuster la sensibilité :

• /setup aimode light — Détection moins agressive

• /setup aimode normal — Équilibré (par défaut)

• /setup aimode strict — Détection maximale (pour gros serveurs)

Vous pouvez aussi exempter des rôles ou des salons avec /whitelist.

Le dashboard est-il sécurisé ?

Oui, totalement. Voici comment :

• Authentification via OAuth2 officiel Discord — vous ne partagez jamais votre mot de passe

• Le bot vérifie que vous avez la permission Gérer le serveur avant toute modification

• Toutes les actions sont logées dans le salon de logs de votre serveur

• Le code source est public — vous pouvez vérifier qu'il n'y a aucun comportement malveillant

Que se passe-t-il si un de mes membres se fait pirater ?

Si SecureCore détecte un compte piraté (token grabber, spam scam) :

1ère infraction — Mute 24h + DM avec instructions pour récupérer le compte (changer mot de passe, activer 2FA).

2ème infraction — Mute 48h.

3ème infraction — Ban définitif (compte considéré comme perdu).

Cette escalade permet aux vrais utilisateurs de récupérer leur compte sans perdre leur place dans votre serveur.

Mes données sont-elles partagées ?

Non. SecureCore ne collecte que ce qui est nécessaire au fonctionnement du bot :

• ID de votre serveur et configuration (pour appliquer les bons réglages)

• Historique des sanctions (pour l'escalade)

• Logs des actions (pour la transparence)

Ces données restent uniquement sur le serveur d'hébergement du bot. Aucun partage à des tiers, aucune monétisation.

Le bot peut-il faire tomber mon serveur ?

Non. SecureCore est conçu avec des garde-fous :

• Le bot s'ignore lui-même (ne sanctionne jamais ses propres actions)

• Avant chaque sanction massive, il vérifie le contexte (vraie attaque vs faux positif)

• Vous pouvez créer des backups avec /backup create pour restaurer rapidement

• Toutes les sanctions automatiques sont annulables manuellement

Puis-je obtenir un bot custom ?

Oui ! Rejoignez le serveur Discord et envoyez un message dans le salon #demandes-custom. On vous répond sous 24h avec un devis.

Exemples de bots déjà développés : ticket avancé, économie, stats, modération custom, intégration Twitch/YouTube, etc.
